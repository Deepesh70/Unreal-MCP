The Autonomous MCP Orchestrator
The Unreal-MCP project has been successfully updated to natively act as a fully autonomous MCP server. This eliminates the need for the intermediate agent.py Langchain script and allows any external orchestrator (such as Claude Desktop, Cursor, or your own LLM application) to connect directly to the FastMCP server and exercise complete control.

New High-Level Orchestration Tools
I have created a new module unreal_mcp/tools/orchestrator.py which provides the orchestrator with four specific, powerful tools to manage its environment and assets:

1. query_local_space
Purpose: Gives the LLM situational awareness without flooding the context window.
Functionality: Wraps the spatial querying logic to allow the LLM to search for nearby actors relative to a specific target actor within a defined radius.
2. search_asset_database
Purpose: Exposes the local ChromaDB vector store directly to the MCP Server.
Functionality: The LLM can query semantic terms (e.g., "wooden chair", "concrete wall") and receive the exact Unreal Engine asset paths required for building, ensuring it doesn't hallucinate non-existent assets.
3. draft_procedural_blueprint
Purpose: Enforces strict typing and JSON structure validation.
Functionality: Uses FastMCP's Pydantic schema generation to provide a strongly-typed tool interface. The LLM supplies intent, structure_id, requested_loc, asset_path, transforms, parameters, and parts. The tool validates the inputs and outputs a perfect JSON string ready for the C++ backend.
4. execute_and_compile
Purpose: The final execution step.
Functionality: Takes the valid JSON string generated by draft_procedural_blueprint and routes it through process_agent_output(). This forwards the payload via WebSocket to AProceduralCityManager inside Unreal Engine, compiling the procedural blueprint and returning a receipt (e.g., "✅ Built 'House_01'").
Registration and Validation
These tools have been registered in unreal_mcp/tools/__init__.py. When you run unreal-mcp (or python server.py), the server now exposes these powerful orchestration capabilities automatically.

How to use
Any connected client can now execute workflows like this entirely autonomously:

Call search_asset_database("street lamp") to find the correct mesh path.
Call query_local_space("Road_01") to find the road's location.
Call draft_procedural_blueprint(...) to assemble the mathematical JSON for placing the lamps.
Call execute_and_compile(...) to spawn the instances in Unreal Engine.
